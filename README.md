# 沙呂城的夜市

浸信會沙田圍呂明才小學的小三中文溫習遊戲。走進紙藝古城，挑戰排比句、比喻、歎詞和標點符號，收集四盞花燈，點亮夜市。

如果 GitHub Pages 暫時未能開啟，可以[從公開預覽進入同一個遊戲](https://rawcdn.githack.com/chy0282/shalu-night-market/de094a667da1c7539cf4bd78d2954cb5ee69e90b/index.html)。首次進入預覽時，先按「Open the page」，再按「開始探索」。
